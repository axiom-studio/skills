# QuickBooks Skill

Integration with QuickBooks for accounting and financial operations.

## Node Types

- **quickbooks-invoice** — Create and manage invoices
- **quickbooks-report** — Retrieve financial reports (P&L, balance sheet, cash flow)
- **quickbooks-customer** — Manage customer records
- **quickbooks-expense** — Record and track expenses

## Setup

1. Connect your QuickBooks account via OAuth
2. Grant read/write permissions for invoices and reports
3. Use the skill nodes in your agent workflows
