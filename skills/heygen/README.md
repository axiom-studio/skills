# HeyGen Skill

Create and inspect HeyGen avatar videos.

## Nodes

- `heygen-create-video` - Create an avatar video with the HeyGen v3 video API.
- `heygen-get-video` - Retrieve video details and output URLs.
- `heygen-list-voices` - List voices, with optional filters.

## Credentials

Provide a HeyGen API key through the `apiKey` input or the configured connection binding.
